# Documentation Folder

This folder contains written reports, proposals and supporting documents for the CariSurg MedTech Pathways Programme.

## Folder Structure

- `week-0/` contains Week 0 reports and supporting submissions related to clinical triage data cleaning, MAP validation, visualisation, vital sign review, time management and digital ED triage model design.
- `week-1/` contains the Week 1 interim and final preliminary proposal documents.
- `week-2/` contains the Week 2 updated proposal deliverable with Zotero-generated citations and bibliography.

## Navigation Notes

Documents are organised by programme week to make the repository easier to review. The main project README provides the overall repository summary, installation instructions and usage guidance.
