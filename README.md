# Shari's CariSurg MedTech Pathways Portfolio

Welcome to my portfolio repository for the **CariSurg MedTech Pathways Programme**.

This repository will document my progress, submissions, reflections, and project work throughout the 13-week programme. The portfolio will include weekly notebooks, data analysis tasks, clinical AI exercises, technical reflections, and final project materials related to healthcare technology, clinical data, and AI/ML development.

## Programme Overview

The CariSurg MedTech Pathways Programme is designed to develop Caribbean talent in clinical AI, healthcare technology, data analysis, and innovation. Throughout the programme, I will be building technical and professional skills in Python, data analytics, machine learning, clinical reasoning, human-centered design, and portfolio development.

## Repository Purpose

This repository serves as a central space to:

- Store weekly Jupyter/Colab notebooks
- Track my technical progress
- Document clinical AI and data analysis tasks
- Share cleaned datasets or derived outputs when appropriate
- Record reflections and learning notes
- Build a portfolio that demonstrates my development as a Clinical AI Engineer trainee
